RAM Coffers: Why Physical Memory Topology Matters for AI Inference

Most AI infrastructure stories start with a GPU. RAM Coffers starts somewhere stranger and more interesting: the shape of memory inside an IBM POWER8 machine.

Published by tracepatch-lab, June 2026. This article discusses RAM Coffers, part of the Elyan Labs Proof of Physical AI stack.

RAM Coffers is a NUMA-distributed memory architecture for LLM inference. Instead of treating RAM as one flat pool, it treats each memory bank as a place with a role. The repository describes coffers for general knowledge, science and technology, creative or long context work, and niche history. A query is routed toward the coffer whose domain signature best matches the request, then the system activates that bank with thread affinity and cache prefetching before generation.

That sounds academic until you notice the performance claim: 147 tokens per second on an IBM POWER8 S824, or about 8.8x stock llama.cpp on the same class of hardware. The point is not merely that old hardware can still run useful models. The sharper idea is that physical topology is a signal. A NUMA node, a cache hierarchy, and an instruction set are not annoyances to abstract away; they are knobs the inference path can use.

A Different Kind of Efficiency

Modern AI optimization often focuses on compression, quantization, and accelerator kernels. RAM Coffers adds a complementary question: can we avoid moving irrelevant memory in the first place? Its resonance routing selects a coffer before full weight fetch, and its collapse path prunes candidate routes before expensive work begins. On POWER8, the project also leans on architectural features such as DCBT prefetching, VSX vector paths, and even hardware AES instructions explored as attention-collapse primitives.

This is useful because memory bandwidth is often the ceiling for local inference. If a model request only needs a particular slice of stored knowledge, fetching every slice is wasteful. RAM Coffers reframes the machine as a library with aisles, not a warehouse with one giant loading dock. The route matters. The shelf matters. The latency of walking to the shelf matters.

The practical insight: hardware age does not automatically mean hardware irrelevance. With the right routing layer, a vintage server can become a specialized inference node instead of e-waste.

Why This Fits RustChain

RAM Coffers belongs naturally beside RustChain and Proof of Antiquity. RustChain rewards physical, attestable machines rather than disposable virtual workers. RAM Coffers gives those machines a productive job: perform local AI inference in a way that depends on their actual memory and CPU characteristics. The same box can be understood as both infrastructure and provenance.

That matters for decentralized AI because "more compute" is not a complete strategy. A network also needs diversity, auditability, and reasons for older machines to stay online. POWER8, PowerPC Macs, legacy servers, and other uncommon systems are awkward for the cloud monoculture, but they are rich with physical fingerprints. RAM Coffers turns that awkwardness into an architectural feature.

What Builders Should Take From It

The reusable pattern is not limited to POWER8. A builder can ask three questions on any local inference system: what memory regions are distinct, what work should be routed to each region, and what hardware-specific operations make the route cheaper? On Apple Silicon, that may mean MLX-oriented memory behavior. On x86, it may mean NUMA placement, huge pages, or cache-aware batching. On vintage hardware, it may mean accepting constraints and designing with them instead of pretending the machine is a tiny cloud instance.

RAM Coffers is compelling because it treats inference as situated computation. The prompt, the model weights, the memory bank, the CPU instruction, and the chain identity all live in one story. That story is exactly what makes Elyan Labs projects interesting: they do not ask old machines to cosplay as new ones. They ask what the old machines uniquely know how to do.
